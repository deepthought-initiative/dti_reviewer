.. py:function:: initialize_similarity_engine()

   Create and load the search engine once for this Python process.

   :returns: The result is the shared search engine for this process.
   :rtype: SimilarityEngineOrcid

   .. rubric:: Notes

   The first call loads the index. Later calls reuse the engine. Errors
   while loading the index are not caught here.


.. py:function:: query_experts_task(self, vector_id: str, top_n: int = 25)

   Run an expert search in the background using a stored vector.

   :param self: Celery supplies this task object so the function can report progress.
   :type self: celery.Task
   :param vector_id: This is the stored vector ID returned by ``save_vector``.
   :type vector_id: str
   :param top_n: The search uses this result limit. The default is 25.
   :type top_n: int, optional

   :returns: Each match contains ``orcid``, ``author``, ``similarity``, and
             ``name_variations``.
   :rtype: list of dict

   :raises ValueError: The task raises this error if the vector is missing or has expired.

   .. rubric:: Notes

   The task reports progress as 0.05, 0.10, 0.90, and 1.0. These are fractions,
   so 1.0 means 100 percent. Celery handles any errors raised by the search.
