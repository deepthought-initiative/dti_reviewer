auth.load_user(user_id)¶

Find the logged-in user by their revocable session identifier.

Parameters:

user_id (str) – Flask-Login supplies this identifier from the session.

Returns:

The result is the matching user, or None if the user no longer exists.

Return type:

User or None

Notes

Flask must know which app is using the database. It sets this up during requests. In a standalone script, call this inside with app.app_context():.

auth.protect_auth()¶

Check the CSRF token before handling an unsafe request under /auth.

Raises:

flask_wtf.csrf.CSRFError – The check raises this error if the CSRF token is missing or invalid.

Notes

The CSRF token helps prevent another website from submitting a request using the user’s login session.

auth.user_session()¶

Return the login status and CSRF token for GET /auth/session.

Returns:

The JSON response contains user_id, auth_mode, and csrf_token with status 200. The user ID is null when nobody is logged in. The browser is told not to cache this response.

Return type:

flask.Response

auth.login()¶

Handle login requests at /auth/login.

Returns:

GET sends the browser to the external provider or the local login page. POST logs in a local user and returns status 200 on success. It returns status 401 for an incorrect username or password, or status 400 when external login is enabled.

Return type:

flask.Response or tuple of (flask.Response, int)

Notes

POST requests supply username and password as form fields and need a valid CSRF token. Successful login replaces the previous session.

auth.callback()¶

Finish an external login when the provider calls /auth/callback.

Returns:

Successful login sends the browser to the home page. The response has status 404 if external login is disabled, or status 400 if exchanging the login token fails.

Return type:

flask.Response or tuple of (flask.Response, int)

Notes

The provider name and its user ID identify the local user record. This function creates that record if needed and replaces the previous session.

auth.logout()¶

Log out the user and clear their session at POST /auth/logout.

Returns:

The response contains message="Logged out" and status 200.

Return type:

flask.Response

Notes

The request needs a valid CSRF token.

auth.create_user(username, password, admin)¶

Add a local user with the Flask create-user command.

Parameters:

  • username (str) – The username is saved after surrounding spaces are removed.

  • password (str) – The password is hashed before it is saved. The command asks the user to enter it twice.

Raises:

click.ClickException – The command raises this error if either value is empty or the username already exists.

Notes

The command saves the new user and prints a confirmation. Run it through the Flask CLI so Flask can select the app’s database.

auth.init_auth(app)¶

Set up login, logout, and the user creation command for the app.

Parameters:

app (flask.Flask) – The app supplies AUTH_MODE and the settings for external login.

Raises:

ValueError – Setup raises this error if the mode is not local or oidc, or a required external login setting is missing.

Notes

The oidc mode connects to an external login provider. The local mode prepares a dummy password hash so unknown usernames still go through a password check.
