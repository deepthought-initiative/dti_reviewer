app.create_app(test_config=None)¶

Create the Flask application and initialize its database and authentication.

Parameters:

test_config (mapping, optional) – These settings override the defaults read from environment variables. If omitted, the app reads config.py from its instance directory.

Returns:

The app is ready to handle login and API requests.

Return type:

flask.Flask

Raises:

ValueError – The app raises this error if SECRET_KEY is missing, AUTH_MODE is invalid, or required external login settings are missing.

Notes

This function also creates the database directory and user table.
