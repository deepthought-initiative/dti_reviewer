api.get_query(client_ip)¶

Read and validate the query in the current JSON request.

Parameters:

client_ip (str or None) – This address identifies the client in log messages.

Returns:

  • query (str or None) – The query has surrounding spaces removed. It is None if validation fails.

  • error (tuple of (flask.Response, int) or None) – This contains a JSON error message and status 400 if validation fails. It is None when the query is valid.

Notes

Call this function while Flask is handling a request. The JSON body should be an object with a query string containing at least three characters after spaces are removed. Errors from reading the JSON are not caught here.

api.vectorize()¶

Handle POST /vectorize by storing a query vector in Redis.

Returns:

The response contains vector_id and status 201 on success. Invalid queries return status 400. Other errors return status 500.

Return type:

tuple of (flask.Response, int)

Notes

The request body supplies query. It must contain at least three characters after surrounding spaces are removed. The stored vector expires after one hour. Errors from reading the JSON also return status 500.

api.search()¶

Handle POST /search by queuing a search for a stored vector.

Returns:

The response contains message, task_id, and status 202 when the search is queued. An invalid vector ID returns status 400. Other errors return status 500.

Return type:

tuple of (flask.Response, int)

Notes

The JSON body must supply a nonempty vector_id string. The worker checks whether the vector exists and finds up to 25 matches. Errors from reading the JSON return status 500.

api.task_status(task_id)¶

Handle GET /status/<task_id> by reading the Celery task result.

Parameters:

task_id (str) – This is the task ID supplied in the URL.

Returns:

The JSON response always includes state. PENDING and PROGRESS return status 202, and PROGRESS also includes percent. SUCCESS includes results and returns status 200. Other states return an error message and status 500. A failed status lookup returns state ERROR and status 500.

Return type:

tuple of (flask.Response, int)

Notes

The percent value is a fraction: 0.5 means 50 percent. Unknown task IDs usually appear as PENDING too.
